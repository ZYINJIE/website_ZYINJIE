欢迎来到胤捷的小破站压缩包。
============================

【怎么用】
1. 解压
2. 双击 index.html（别用 IE，求你了）
3. 想放到服务器上，直接把整个文件夹传上去就行，不需要任何配置

【改成你自己的】
- 把五个 html 里所有「胤捷」替换成你的名字（或者你的绰号）
- 「好朋友」那页的链接是我编的，记得换成真人
- 碎碎念随便删随便加，notes.html 里复制一个 <article> 就行
- 想换颜色：打开 style.css，改最上面的 :root 那几行

【技术栈】
一个 html + 一个 css + 一个 js。没有框架。
所以它永远不会坏，也永远不会自动更新——我觉得这是优点。

【关于彩蛋】
- 按上上下下左右左右BA（Konami 秘技），整个网站会倒过来
- 拉到页面最底下，连点三次 © 会弹奖状
- 按 F12 看 console，有给你留的话

【已知问题】
- 留言板数据存在你浏览器里，换电脑就没了（故意的，省服务器钱）
- 404 页在本地双击时不会触发，要部署到服务器上才生效
