▸ 本站历史（一个自我考古展）

  • v1 · 2019 用表格布局做的，被同学笑了半年，文件已丢失（其实是自己删了，因为太丢人）。
  • v2 · 2021 用了某个大而全的 CSS 框架，所有页面长得一模一样，像从模板站批发来的。三个月后后悔。
  • v3 · 2023 上了 WordPress，装了一堆插件，被攻击了两次，服务器到期后跑路了。
  • v4 · 现在 一个 html + 一个 css + 一个 js。没有框架，所以它永远不会坏，也永远不会自动更新——我认为这是优点。

▸ 几条原则

  1. 不追热点，热点追我我都不理。
  2. 不写"赋能""闭环""抓手"这类词，写一个罚款十块（自我罚款，钱直接扔掉）。
  3. 网站不放广告。要是哪天你看到广告了，说明我饿死了，麻烦帮忙报警。
  4. 留言不审核，骂我的也显示。反正你也看不见别人的留言。
